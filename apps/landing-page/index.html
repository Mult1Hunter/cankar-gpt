A Slovene micro-LLM, trained from scratch

CankarGPT ❧

A 26-million-parameter language model built from nothing but public-domain text, then taught the prose voice of Ivan Cankar (1876-1918). No pretrained base. No API. Trained on one desktop GPU for about the price of nothing.

„Mati, ali je model že konvergiral?“

! This is a 26-million-parameter model. Its Slovene reads fluently, but it does not yet form fully coherent sentences - that is expected at this size, not a bug. A later stage brings in a larger GaMS-based Slovene model to close the gap. How it works ->

The foundation

done - phases 0-4

  • Corpus - public-domain literature plus Slovenian Wikipedia, cleaned, deduplicated and merged (~73M words).
  • Tokenizer - a custom Slovene sub-word vocabulary, trained from scratch on that corpus.
  • Eval harness - a frozen held-out set and a style classifier, so quality is measured, never claimed.
  • TinyCankar -> base -> v1 - a tiny proof of life, then general Slovene, then Cankar's voice.

The product

next - phases 5-6

  • Style pairs - synthetic plain <-> Cankar sentence pairs, generated with a large model.
  • The styler - fine-tune on those pairs so you feed in plain modern Slovene and get the same meaning back in Cankar's register.
  • This is where a tiny model earns its keep: it supplies the voice, the meaning comes from the input.

The reach

later - phases 7-9

  • Serving - a free CPU endpoint, with a stretch goal of running the model fully in the browser.
  • Two-tier demo - "write like Cankar" plus "ask Cankar", the second pairing a knowledge model with the styler.
  • GaMS v2 - a fine-tune of a larger Slovene base model, as an honest quality yardstick.

The current model continues a prompt in Cankar's voice. The next stages turn it into a styler: give it a plain modern-Slovene draft, get back the same meaning in Cankar's register. That is where a tiny model earns its keep - it supplies the voice, while the meaning comes from the input.

how it was built

Technical overview

Corpus
126,355 documents, 72.3M words - Slovenian Wikipedia + 15 public-domain authors; the Cankar slice is 2.92M tokens
Tokenizer
custom Slovene BPE, 8,192 vocab - 1.77 tokens/word on Cankar; trained from scratch on the merged corpus
Model
26.3M-param GPT - 6 layers, 384-dim, 6 heads, 1,024 context; bf16, flash attention
Training budget
142.77M tokens - base: 3 epochs, loss 9.0 -> 2.8; specialization: ~3 gentle epochs on Cankar
Hardware
one RTX 4070 Ti Super (16GB) - 264k tokens/sec; base pretrain ~27 minutes; run locally, €0
Evaluation
held-out BPB + style classifier - frozen 50-work holdout, containment-checked; confound-audited AUC 0.993
in plain words

What the terms mean

Bits per byte (BPB)
How surprised the model is by real Cankar text. Fewer bits = better prediction. Lower is better.
Token / BPE
The model reads text in sub-word pieces called tokens; a BPE tokenizer learns those pieces from the corpus itself.
Parameters
The numbers the model learns (its weights). 26 million here - tiny; frontier models have 100,000x more.
Epoch
One full pass over the training text. This model saw its corpus about three times.
Held-out set
Works deliberately kept out of training, used only to test - so a good score cannot be memorization.
Specialization
Extra training of the general model on Cankar alone, to shift its register toward his voice.
Temperature
How much randomness the sampler allows. Higher is more varied and riskier; lower is safer and flatter.
Style classifier
A separate detector that tells Cankar's prose from 14 other authors', used to measure how "Cankar" the voice is.
the honest part

What this is, and what it is not

What it is

  • A from-scratch demonstration that a tiny model can learn a distinct Slovene literary voice from ~3M tokens.
  • Locally fluent: grammar, morphology, and Cankar's melancholic cadence are convincingly there.
  • Fully measured - every number here comes from a frozen eval harness, not from vibes.

What it is not

  • Not logically coherent across a paragraph - at 26M parameters that is a scale floor, expected, not a bug.
  • Not the styler yet: v1 continues a prompt; the plain->Cankar rewrite comes in a later stage.
  • Not affiliated with Ivan Cankar or any institution - this is an AI pastiche, built for learning.
