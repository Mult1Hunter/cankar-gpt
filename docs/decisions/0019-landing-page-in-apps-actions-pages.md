# ADR 0019 - public landing page in apps/landing-page, deployed via Actions Pages

**Status:** withdrawn - content moved, .github/workflows/pages.yml and tests/structure/test_layout.py (2026-07-26)

## Context

Putting a website under apps/ and deploying it with a workflow is the conventional answer. Both real facts are already comments in the files that implement them.

## Decision

Withdrawn as a standing record. The content lives at `.github/workflows/pages.yml and tests/structure/test_layout.py`; this number
is retained so existing `ADR 0019` citations still resolve.

## Consequences

Nothing changes mechanically - see ADR 0023 for the consolidation that produced
this stub, and `docs/decisions/README.md` for where each topic now lives.
