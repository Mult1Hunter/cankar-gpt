# ADR 0009 - thematic commits, merge-commit PRs

**Status:** withdrawn - content moved, CONTRIBUTING.md (2026-07-26)

## Context

A workflow convention stated in four places already. Its one non-obvious footnote - merge commits preserve SSH-signed branch commits, so Verified survives - now lives in CONTRIBUTING.

## Decision

Withdrawn as a standing record. The content lives at `CONTRIBUTING.md`; this number
is retained so existing `ADR 0009` citations still resolve.

## Consequences

Nothing changes mechanically - see ADR 0023 for the consolidation that produced
this stub, and `docs/decisions/README.md` for where each topic now lives.
